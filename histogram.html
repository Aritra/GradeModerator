Warning: grade changes made here cannot be reverted. To undo them you must start the grading process again (reload the marks and ERP files, or a previously saved JSON). Moving a student back to a letter grade after the cutoffs have been changed would silently drop them into whatever band the new cutoffs give, changing the grade counts and the MGPV you have already moderated, so undo is deliberately not offered.

Before the changes are applied, the current grades are saved automatically as a JSON file named AUTO_BACKUP_ followed by the usual Save Grades file name. To go back to the state before the changes, open that file with View Grades on the home page.
