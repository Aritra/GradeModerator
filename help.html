    What the Grade Moderator does

    The Grade Moderator helps an instructor turn final marks into letter grades and fill them into the student list downloaded from ERP. It runs entirely in your web browser: nothing is uploaded to a server, and your files never leave your computer.

    1. You give it the students' marks (pasted from Excel or Google Sheets) and the ERP student list (a CSV file).
    2. It draws a histogram of the marks: how many students got each mark.
    3. You place the grade cutoffs (A, A-, B, … E) by dragging them, usually into the gaps or valleys of the distribution. Grade counts and the MGPV update as you drag.
    4. You export the ERP CSV with marks and grades filled in, ready to upload back to ERP, and save your work as a JSON file to continue later.

    The page needs an internet connection the first time it opens, to load its styling and charting libraries (Bootstrap and Chart.js). Google Chrome gives the best results; Firefox, Edge and Safari also work.

    Privacy and data security

    The Grade Moderator is a static website that runs entirely within your web browser. It has no server-side component: marks, student details and files are never uploaded, transmitted or stored on any server. The application can read only the files that you choose to open yourself, and it has no access to any other information on your computer. Apart from downloading the pages and their standard open-source libraries (Bootstrap and Chart.js), it makes no network connections. Work in progress is kept only within your own browser tab (so that a page refresh does not lose it) and in the JSON and CSV files you choose to download.

    Quick start

    1. On the home page click New Grade.
    2. Enter the subject name and the maximum marks of the course.
    3. Copy two columns from your spreadsheet, Student ID and Marks, and paste them into the paste box.
    4. Choose the starting row: the first row that contains a student (2 if you copied one header row, 1 if you copied no header).
    5. Choose and submit the ERP CSV file exactly as downloaded from ERP (do not rename it).
    6. Click Show Histogram. If students in the ERP file are missing from your marks, enter their marks when asked. If some students have non-letter grades, a list of them is shown next; click OK.
    7. Drag the grade bubbles above the chart to set the cutoffs.
    8. Click Save Grades to keep a JSON backup, then Save ERP CSV to get the file for ERP.

    No files of your own yet? Download a practice pair from Practice files.

    How to practise

    1. Download both files of one course (keep the ERP file's name as it is: the course code is read from it).
    2. Open the marks file in Excel, LibreOffice or Google Sheets and copy its two columns, including the header row.
    3. On the home page click New Grade, enter the course name and the maximum marks from the table, paste the marks and choose starting row 2.
    4. Choose and submit the ERP file, then click Show Histogram. The withdrawn students are listed in the Special Grades window; they appear in the marks file too, but are kept out of the histogram because ERP already gives them W.

    To try View Grades, download the saved grades file CHEM F111_JSON_saved_3-11-2026-13-38-36.json (General Chemistry, 800 students, already set up) and open it from the home page.

    • New Grade: start grading a course from marks and an ERP file.
    • View Grades: open a JSON file saved earlier with Save Grades and continue from exactly where you left off (cutoffs, non-letter grades, title). A file that is not a valid grades file, or that lists the same student more than once, is refused with a message.

    Entering marks (paste from Excel or Google Sheets)

    Select the Student ID and Marks columns in your spreadsheet, copy them, click in the paste box and press Ctrl+V (Cmd+V on a Mac). The first column must be the ID and the second the marks.

    What happens to pasted data

    • Preview table: the pasted rows are shown as a table, each with its row number.
    • Empty rows at the start and end are removed automatically (copying whole columns often brings hundreds of blank rows).
    • Two-column check: if any row has more than two filled columns, those rows are shown in red and the paste is rejected; paste only the ID and Marks columns. Pasting a single column is also rejected. An empty extra column is ignored.
    • Decimal marks are rounded up to the next whole number (45.2 becomes 46, 45.0 stays 45), because grading works on whole marks. The status line says how many were rounded.
    • IDs are converted to capital letters (digits are unchanged) and spaces around them are removed, for example 2023a7ps0412h becomes 2023A7PS0412H. A header such as “Student ID” is left as it is. The status line says how many IDs were converted.

    Starting row

    Pick the row number (as shown in the preview) of the first student. Rows above it are treated as headers and shown in dark blue; the student rows are shown in light yellow.

    ID format check

    Once the starting row is chosen, every student ID is checked against the BITS format: a 4-digit year, a 4-character programme code, a 4-digit roll number and a campus letter (13 characters, such as 2023A7PS0412H). Transfer students end in two or three different campus letters from G, H and P instead, in any order (for example 2023A7PS0412GH, …HP, …GHP); see Student ID format. Rows with an invalid or empty ID are shown in red with a message, and Show Histogram will not continue until they are fixed in your sheet and pasted again. Completely empty rows are ignored.

    Duplicate ID check

    Each student may appear on only one pasted row. If the same student is on two or more rows, those rows are shown in red, the message lists them (for example 2023A7PS0412H (rows 5, 9)), and Show Histogram will not continue until you keep one row per student and paste again. IDs count as the same student when the year, roll number and campus letter agree (see How students are matched), so 2023A7PS0412H and 2023B4A70412H are duplicates.

    Coming back with the Back button

    The New Grade and View Grades pages are cleared every time they are opened, including with the browser's Back button, so details from a previous course are never reused by mistake.

    The ERP CSV file

    Download the student list for your course from ERP as a CSV file and choose it in the second upload box. Only .csv files are accepted.

    Do not rename the ERP file. The course code is read from the file name. For example, H0827_CS_F213_1159_MIDSEM.csv gives the course code CS F213 (the 2nd and 3rd parts of the name, separated by underscores).

    Duplicate students in the ERP file

    When the ERP file is submitted, it is checked for students listed more than once (same year, roll number and campus letter). Such a file is rejected with a message naming the student(s) and the line numbers in the file, because grades are written back by ID and a duplicate would make the result ambiguous. Download a fresh copy from ERP, or delete the extra lines (without renaming the file), and submit it again.

    How students are matched

    The ERP list decides who is in the course. For every student in the ERP file:

    • The student's ID is looked up in your pasted marks. IDs are matched on the year of admission, roll number and campus letter(s) only (for 2023A7PS0412H: 2023, 0412 and H; for a transfer student's 2023A7PS0412GH: 2023, 0412 and GH, so it does not match …0412H). The programme code in the middle (A7PS, B4A7, …) is ignored, as are upper/lower case and spaces, so a student whose branch is written differently in your sheet and in ERP still matches. The ID shown and exported is always the one from the ERP file.
    • If the ERP Grade column already holds a non-letter grade (W, I, NC, GA, RC, DP, TGA or RRA), the student is not placed in the histogram; they are listed separately with that grade.
    • If the student is missing from your marks:
      • a withdrawn (W) student is listed separately with marks 0, as usual;
      • for anyone else, a Students missing from your marks window opens when you click Show Histogram, listing their ID, name and ERP grade with a box for their marks. Enter a mark (0 to the maximum; decimals are rounded up) for every student and click Continue, or click Cancel and fix the pasted marks. The entered marks are then used exactly as if they had been pasted.
    • Everyone else is letter-graded and appears in the histogram.

    If any students are listed separately, a Special Grades Found window shows them before the histogram opens. The ERP file is the master list: students who are in your marks but not in the ERP file are simply ignored.

    The histogram page

    Top panel

    • Course code and name, with a pencil button to edit them (see Editing the course title).
    • Total Students: everyone in the ERP list. Students Graded: students currently receiving a letter grade. Maximum Marks, Average Marks (over letter-graded students) and the MGPV.
    • Non Letter Grades table: how many students have W, I, NC, GA, RC, DP, TGA and RRA.
    • Letter Grades table: the cutoff (minimum marks) and number of students for each grade.

    The chart

    • One bar per whole mark; the bar height is the number of letter-graded students with that mark.
    • The x-axis runs from the lowest to the highest letter-graded mark, widened by 5 marks on each side (but never below 0 or above the maximum marks).
    • Click a bar to see the students with that mark and the grade they currently get.

    The page scales with your screen: text, buttons and the chart grow or shrink with the window.

    While the page is opening, a spinning circle with “Loading grades and drawing the histogram…” is shown; it disappears as soon as the histogram is drawn. If there is nothing to load (for example the page was opened from a bookmark or in a new tab) or something goes wrong, the circle is replaced by a message with a link back to the home page.

    Grade cutoffs and the draggable bubbles

    Each letter grade has a cutoff: the minimum marks needed for that grade. Each cutoff is drawn as a vertical line with a round bubble on top showing the grade's name.

    How a grade is decided

    A student gets the highest grade whose cutoff is at or below their marks. For example, with B at 120 and B- at 105, a student with 119 marks gets B-. A student below the E cutoff gets no letter grade; such students are normally given NC (see Non-letter grades).

    Moving a cutoff

    • Drag a bubble left or right. It snaps to whole marks.
    • A cutoff cannot pass its neighbours: it always stays at least one mark above the grade below and one mark below the grade above.
    • The grade tables, Students Graded, MGPV and chart update while you drag.
    • Neighbouring bubbles alternate between a short and a long stick so they do not overlap when cutoffs are close together.

    When a new course opens, the 8 cutoffs are spaced evenly across the x-axis as a starting point. Grades are usually set by moving each cutoff into a gap or valley in the distribution, so students on either side of a cutoff are clearly separated.

    Bubbles work with a mouse, a touchscreen or a pen.

    MGPV (Mean Grade Point Value)

    Each letter grade carries a weight, its grade points:

    GradeAA-BB-CC-DE
    Grade points109876542

    MGPV = Σ (grade points × number of students with that grade) ÷ number of letter-graded students. Non-letter grades (W, NC, …) do not count.

    Example: 2 A, 5 B and 3 C → (2×10 + 5×8 + 3×6) ÷ 10 = 78 ÷ 10 = 7.80. The MGPV shown is cut (not rounded) to two decimals.

    Hover over the Letter Grades table to see each grade's weight and how much it adds to the MGPV; hover over the left-hand column to see the full calculation with the current numbers.

    Non-letter grades (W, I, NC, GA, RC, DP, TGA, RRA)

    • W (withdrawn) always comes from the ERP file; it cannot be given in this tool.
    • Other non-letter grades can come from the ERP file, or you can give them to letter-graded students in Search/Edit Grades.
    • Hover over the Non Letter Grades table to see the ID and name of every student with a given grade (the first 25 are listed, then “… and N more”).

    Two common guidelines for NC: marks below 40% of the class median, or below 30% of the average of the top K students. The NC Calculator works out both (both percentages and K can be changed), and the red ✕ button next to it can give NC to everyone below the line. Write the NC criterion you used in the box shown when you click Print PDF.

    NC Calculator and NC zone

    Click NC Calculator (orange, the first of the buttons below the histogram). Choose the rule for the NC line:

    • a percentage of the median marks; type the percentage (40 to start with; more than 0, at most 100), or
    • a percentage of the average marks of the top K students; type the percentage (30 to start with; more than 0, at most 100) and K (3 to start with; a whole number from 1 to the class size).

    The window shows how the line was worked out (the median or the top-K average), the NC line itself, and the students with marks below it (ID, name, marks and their current grade). Marks are whole numbers, so a line of 70.4 means 70 or less.

    Turn on Shade the NC zone on the histogram to colour the chart light red from the left edge up to the NC line, with a dashed red line at its edge. The shading follows the data as you work and is included in Print PDF. Turn the switch off to remove it.

    • The calculation uses the students in the histogram plus anyone already given NC (so giving NC in Search/Edit Grades does not move the line); W and the other non-letter grades are left out.
    • The calculator itself does not change any grade. To give NC, use the red ✕ button (below) or Search/Edit Grades.
    • The chosen rule, both percentages, K and the switch are kept when you refresh the page and are saved in the Save Grades file.

    Mark everyone in the NC zone as NC (red ✕ button)

    The round red button with a white cross, just to the left of NC Calculator, gives NC to every letter-graded student below the NC line in one step, using the rule, percentages and K currently chosen in the NC Calculator (whether or not the shading is switched on). It asks first: “Mark everyone in NC zone as NC and redraw histogram and reset minimum marks in histogram?”, and lists the NC line and the students it will change. Click Cancel to leave everything as it is, or Yes to:

    1. download a backup of the current grades first, as a JSON file named AUTO_BACKUP_ + the usual Save Grades name (open it with View Grades to undo), exactly as in Search/Edit Grades;
    2. give those students NC (they move to the Non Letter Grades table, keeping their marks);
    3. redraw the histogram starting from the new lowest letter-graded mark (minus 5, as when the page opens; the highest mark stays). If a grade cutoff would now be below the start of the chart, it is moved up to the first mark of the chart, and cutoffs above it are nudged up only if needed to stay in order; check the lowest grades' bubbles afterwards.

    If no letter-graded student is below the line, the dialog says so and Yes is disabled.

    Search/Edit Grades

    Lists every student with ID, name, marks and grade. Type in the search box to filter by name or ID.

    Changing a letter grade to a non-letter grade

    1. Click a letter-graded student. Their details appear below the table with a dropdown.
    2. The dropdown starts on the current letter grade; choose I, NC, GA, RC, DP, TGA or RRA. The change is pending and shown in red (for example B- → NC). Choosing the current grade again cancels it.
    3. Repeat for as many students as needed.
    4. Click I am done! and confirm. The changes are applied together.

    The students are removed from the histogram and all tables, counts, the MGPV and the average are refreshed. Their marks are kept (they are written to the ERP file and the saved JSON). Cutoffs and the x-axis do not move.

    Automatic backup: when you confirm, the grades as they were before the changes are first downloaded as a JSON file named AUTO_BACKUP_ followed by the usual Save Grades file name (for example AUTO_BACKUP_CS F213_JSON_saved_3-11-2026-14-5-2.json). To go back, open that file with View Grades on the home page.

    These changes cannot be undone on the page itself. To undo them, open the automatic backup (or another JSON saved before the change) with View Grades, or start again from your files. Moving a student back to a letter grade after the cutoffs have changed would silently drop them into whatever band the new cutoffs give, changing grade counts and the MGPV you had already moderated, so undo is deliberately not offered.

    Grade Analytics

    Shows the number of students in each active letter grade as a bar chart, or as a pie chart with Show Pie Chart. The heading also says which grade band the class average falls in.

    Editing the course title

    Click the pencil next to the course title to edit the course code and subject name. Click the tick or press Enter to keep the change, or Esc to cancel. An empty box keeps its old value. The new title is used for the browser tab, the saved JSON and its file name. The ERP CSV keeps its original ERP file name.

    Saving and exporting

    Save Grades (JSON backup)

    Downloads a JSON file with everything needed to continue: marks, ERP list, cutoffs, non-letter grades and title. Open it later with View Grades on the home page. Save one before making changes you might want to go back on.

    Save ERP CSV

    • Export Directly: fills each student's marks and grade into the ERP file and downloads it with its original name (a preview also opens in a new tab). If an ERP student cannot be found in either list, you are warned and they are marked W with 0 marks; fix that row by hand.
    • Sort by Branch/Campus: opens a page where the students can be ordered by campus, by branch, or by both, before downloading. Campus and branch are read from the student ID and shown for reference only; the downloaded file has just the ERP columns.

    Print PDF

    Asks for the NC cutoff and criterion (up to 200 characters), which is printed below the chart, then opens the print dialog in landscape. Choose “Save as PDF” to get a PDF. Click the ✕ next to the criterion text afterwards to bring the buttons back.

    Refreshing the page and keeping your work

    While you work, the histogram page keeps a copy of its current state in the browser tab. Refreshing the page brings back your cutoffs, non-letter grades and title.

    This copy lives only in that tab. Closing the tab, or opening the page in another tab, loses it. Use Save Grades to keep your work between sessions.

    Student ID format

    BITS student IDs have 13 characters, for example 2023A7PS0412H (transfer students have 14 or 15, see below):

    CharactersMeaningExample
    1–4Year of admission2023
    5–8Programme: A7PS = single degree (A7), B4A7 = dual degree (B4 and A7)A7PS
    9–12Roll number0412
    13Campus: H = Hyderabad, P = Pilani, G = GoaH
    13–15Transfer students: two or three different campus letters from G, H, P, in any order (GH, HG, HP, GP, GHP, …)GH

    Any single letter is accepted as the campus; combinations must use only G, H and P, each at most once (GG or GX is rejected). On the sort page a transfer student's campus is shown as, for example, “Goa + Hyderabad”.

    Students are matched between your marks and the ERP file on the year, roll number and campus letter(s) only (the campus part must be identical); the programme code (characters 5–8) is ignored for matching. The sort page uses the campus letter and programme code to group students by campus and branch.

    Troubleshooting

    The course code is wrong (for example “undefined undefined”)
    The ERP file was renamed. Download it again from ERP, or fix the code with the pencil button.
    A “students missing from your marks” window appeared
    Those students are in the ERP list but were not found in your pasted marks (check that their year, roll number and campus letter match). Enter their marks, or Cancel and paste the complete list.
    “student ID(s) are not in BITS format”
    The rows shown in red have an ID that is not in the form year + programme code + roll number + campus letter, or two or three different letters from G, H, P for a transfer student (for example a missing digit, a repeated campus letter, or a name in the ID column). Correct them in your sheet, paste again and choose the starting row.
    “student(s) appear on more than one pasted row”
    The same student (same year, roll number and campus letter) is on two or more of the red rows. Keep one row per student in your sheet, paste again and choose the starting row.
    “The ERP file … lists student(s) more than once”
    The ERP file has the same student on more than one line. Download it again from ERP, or remove the extra lines without renaming the file.
    View Grades says the file lists students more than once, or is not valid
    The JSON file is damaged or was edited by hand. Use another saved copy (for example an AUTO_BACKUP_ file), or create the grades again with New Grade.
    The paste was rejected
    Copy only the Student ID and Marks columns. Rows shown in red have extra columns.
    “… is missing in your sheet but present in the ERP CSV”
    A student in the ERP list was not found in your marks or non-letter lists. They are exported as W with 0 marks; correct that row in the CSV by hand.
    A student I expected is not in the histogram
    They have a non-letter grade in the ERP file, or the year, roll number or campus letter of their ID differs between your sheet and ERP (a different programme code alone does not matter). Check Search/Edit Grades and the Non Letter Grades table.
    I changed a grade to NC by mistake
    Changes in Search/Edit Grades cannot be undone on the page. Open the AUTO_BACKUP_…json file that was downloaded when you confirmed the change (or any JSON saved before it) with View Grades.
    The page has no styling, the chart does not appear, or the loading circle shows an error
    Check your internet connection; the page loads Bootstrap and Chart.js from the internet. Then reload the page. “No grades are loaded in this tab” means the histogram page was opened directly: start from New Grade or View Grades on the home page.
