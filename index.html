Privacy and data security

The Grade Moderator is a static website that runs entirely within your web browser. It has no server-side component: marks, student details and files are never uploaded, transmitted or stored on any server. The application can read only the files that you choose to open yourself, and it has no access to any other information on your computer. Apart from downloading this page and its standard open-source libraries, it makes no network connections, and work in progress is kept only within your own browser tab. You may therefore use it with confidence for confidential grading data.
